# core/install — 설치·갱신·제거

비어 있다. 뒤 유닛이 `sangsoe install`·`uninstall`·`doctor` 를 둔다: 브루가 깐 트리 하나를 `claude plugin marketplace add`·`install` 과 `orca plugin dev load` 로 등록한다(결정 90). Homebrew formula 는 이 저장소가 아니라 별도 탭 저장소에 둔다. OS 상주 작업(OS 스케줄러 등록)은 만들지 않는다.
