# Incident and postmortem context

Run these queries inside your own source:

- **Long-form documents**: postmortems that mention the target file, feature, or error string.
- **Issue tracker**: issues labeled like `incident`, `sev-*`, `postmortem-action-item`, `reliability`.
- **Team chat**: incident channels around the dates the target code was added.
- **Git**: commit messages like "fix for incident", "add defensive check", or a "revert" followed by "re-apply with..." are strong signals.
