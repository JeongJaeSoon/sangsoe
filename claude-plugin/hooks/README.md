# claude-plugin/hooks — 감지 · 토큰 X

`hooks.json` 이 등록 목록이다. 막는 hook `pre-tool-use.sh`(모든 tool 의 PreToolUse 한 줄, `onFailure: "continue"`) → `sangsoe hook pre-tool-use`. 판정은 `core/gates/` 에 있고 이 스크립트는 CLI 를 찾아 부를 뿐이다(찾는 순서는 결정 118). 막음은 스크립트가 낸다(결정 208): 찾은 CLI 가 deny 를 출력하면 그대로 넘기고, 0 이 아닌 코드로 끝나면 2 로 끝내 그 호출을 막는다. CLI 를 하나도 찾지 못하면(sangsoe 가 지워짐) 1 로 끝나 hook 오류 알림만 남기고 호출은 지나간다. plugin 폴더가 없어 hook 이 시작조차 못 하는 것도 막지 않는다: `brew uninstall`·`brew upgrade` 가 폴더를 지워도 돌던 세션이 멈추지 않는다. 기록 hook 일곱(SessionStart · UserPromptSubmit · Stop · Notification · PostToolUse · PostCompact · SessionEnd)은 `record.sh <event>` → `sangsoe hook <event>` 이고 판정은 `core/session/` 에 있다. 기록 hook 은 막지 않는다: CLI 가 없거나 무엇이 실패해도 0 으로 끝나고, SessionStart 만 주입할 줄을 출력한다. UserPromptSubmit 과 Stop 은 끝에 그 세션이 묶인 Run 의 재리뷰 항목을 만든다(결정 219, `core/graph/own-run.ts`): 기다리는 것이 없으면 store 를 읽고 Orca 를 부르지 않는다. 모두 `sangsoe` CLI 를 부르는 command hook 이다: SessionStart 때는 MCP 서버가 없다(결정 75 나).
