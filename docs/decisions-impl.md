# sangsoe 구현 결정

구현하면서 정한 것이다. 번호는 설계 결정(`decisions.md` 1–93)에 이어 94 부터다. 설계가 정한 것을 바꾸는 결정은 바꾸는 결정 번호를 적는다.

94. **런타임은 Node 24.2 이상, 패키지 관리자는 npm 이다.** 설계가 정한 것: 코어는 TS/Node 하나(결정 77 가), sqlite 는 Node 내장 `node:sqlite`, Orca plugin worker 는 `.js`·`.ts` 를 돌린다. 설계가 정하지 않은 것을 여기서 정한다. 24.2 는 `node:sqlite` · 소스 `.ts` 의 타입 제거 실행 · `import.meta.main` 이 모두 기본으로 되는 첫 줄이고, Homebrew 의 `node` formula 가 이를 채운다. npm 은 Node 와 함께 오므로 formula 의 의존이 `node` 하나로 끝난다. 대안: pnpm(속도는 낫지만 formula 가 의존을 하나 더 갖는다) · Bun(`bun:sqlite` 는 설계의 `node:sqlite` 와 다르고 Orca worker 가 돌리는 런타임과 갈린다) · 한 파일 실행본(Node SEA·`bun build --compile`). 한 파일 실행본은 버렸다: 브루가 깔아야 하는 것은 실행 파일 하나가 아니라 매니페스트 둘·skill·패널 파일이 든 트리이고(결정 90), worker 가 코어를 JS 로 import 해야 하므로 실행본이 트리를 줄이지 못한다.
95. **배치는 칸이 최상위인 한 패키지다: `core/`·`cli/`(④) · `orca-plugin/`(②) · `claude-plugin/`(③), 층과 토큰은 하위 폴더로 가른다.** 표는 `architecture.md`. 각 폴더 README 첫 줄의 표지와 `test/layout.test.ts` 가 표·토큰 구분·`core/index.ts` 외 import 금지를 검사한다. 대안: npm workspaces 네 패키지(버전·설정이 네 벌), 최상위를 토큰으로 가름(③ 이 두 뿌리로 찢어짐).
96. **빌드는 `tsc`, 시험은 `node:test`, 린트는 Biome 이다.** 시험은 빌드 없이 `.ts` 소스를 Node 가 그대로 돌린다(`erasableSyntaxOnly`·`rewriteRelativeImportExtensions` 로 소스는 `.ts` 확장자로 import 하고 빌드가 `.js` 로 바꾼다). 개발 의존은 `typescript`·`@biomejs/biome`·`@types/node` 셋이다. 대안: vitest·ESLint(의존이 수십 개 늘고 Node 가 이미 하는 일을 겹쳐 한다).
97. **버전 문자열의 원본은 `package.json` 하나이고 코어가 JSON import 로 읽는다.** 설계의 "코어·두 plugin·MCP 서버는 같은 버전 문자열"(설계 2절)을 손으로 맞추는 목록 없이 지키려는 것이다. 빌드는 `package.json` 을 `dist/` 에 함께 내보내므로 소스 실행과 빌드 실행이 같은 값을 읽는다. 두 매니페스트가 생기면 그 버전도 이 값에서 만들거나 시험으로 맞춘다.
98. **CI 는 작업 셋(`typecheck`·`lint`·`unit`)이고 PR 과 main push 에서 돈다.** `unit` 이 시험 뒤 빌드와 `dist/cli/main.js --version` 까지 돌린다. 금지어 검사는 CI 에 넣지 않는다: 금지어 목록은 전환 직전에 저장소 밖에 둔다(결정 74 의 O-4).
99. **설계 사본은 `docs/` 에 원본 폴더 구조 그대로 둔다.** `decisions.md`·`design.html`·`design-appendix.html`·`glossary.md`·`port-plan.md`·`blog-intro.html`·`diagrams/*.svg`·`dashboard/hallmark-final/`(README 와 html 셋)를 복사했다. 상대 링크가 그대로 풀리게 경로를 지켰다. 조사 노트·스크린샷(`shots/`)·작업용 폴더는 싣지 않았다. 사본의 원본 시각은 2026-11-09 22:46(문서) · 22:48(`hallmark-final/README.md`)이고, 이후 원본이 바뀌면 이 시각과 비교해 다시 복사한다. `design.html` 이 가리키는 `dashboard/zoom.html`·`dashboard/item.html`·`dashboard/README.md`·`dashboard/cli-samples.txt` 는 이번 사본 목록에 없어 링크가 끊겨 있다.
