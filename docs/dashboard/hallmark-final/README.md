## 무엇이 variants/hallmark 와 다른가

- **group.html 의존 그래프 오른쪽 열**: 흩어진 목록·문단·↓ 화살표를 표 5개로 바꿨다. 라벨 스타일(hallmark 의 `th`)과 첫 열 너비(96px)가 같다. 항목 id(i026 등)는 그래프 노드와 표에서 같아 서로 대조해 읽을 수 있다.
  - 크리티컬 패스: 단계 / 항목 / 상태 / 단계 이름. "est 칸이 없어…" 문단은 표 아래 각주로 줄였다.
  - 스택 PR 체인: 층 / PR / 항목 / 상태 (들여쓰기 대신 열 정렬).
  - 릴리스 묶음: 단계 / 조건 / 항목. ↓ 로 이은 글 대신 머지 → deploy_dev → verify_dev → deploy_prod 단계표.
  - 끊긴 선행: 항목 / 끊긴 선행 / 처리. 붉은 상자 대신 배경 없는 보통 행에 붉은 글자(`--bad`)만 쓴다.
  - 간선 종류: 선 모양 / 간선 / 뜻.
- **그래프 SVG**: hallmark 모양을 유지하고 간선 라벨이 노드 테두리에 닿지 않게 오른쪽 열을 56px 벌렸다(viewBox 340→366). 글자는 키웠다(id 11.5px, 이름 10px, 라벨 9px). 붉은 점선 라벨은 `끊긴 선행` 으로 줄였다(간선 종류는 표에 있다).
- **왜 준비되지 않았나**: 문장 목록에서 표로. 항목 / 막는 선행 / 간선 종류 / 선행 상태 / 해야 할 일.
- **좁은 화면(360px)**: 오른쪽 열은 그래프 아래로 내려가고, 표의 모든 칸이 `라벨 | 값` 줄이 되며 라벨 열(64px)이 정렬된다. 넓은 화면은 900px 이상에서만 2열이다(이전의 640px 에서는 오른쪽 열이 40px 로 찌그러졌다).
- **상태 표시줄 시안(B)**: `statusbar.html`(오너 할 일이 있을 때/없을 때, 표기표)과 `index.html` 맨 위의 틀 안 예시. 숫자는 index 와 같다(🚧 5 · 결정 2 · 🔄 5). 오너 할 일이 있으면 붉은 바탕, 없으면 보통 색. 누르면 상쇠 패널이 열린다.
- **오너가 필요한 행에 배경색 없음**(오너, 2026-11-09: "그냥 빨강 배경 안 쓰는 게 맞는 듯"): 🚧 막힌 항목, 결정 필요, 지금 오너가 할 일 행(index)과 🚧 행, 막는 선행 행(group)은 다른 행과 같은 보통 배경이다. 신호는 🚧 마커, 상태 글자, 절 건수뿐이고 대체 색은 없다. 붉은 행 전용이던 토큰(`--bad-soft`, `--own-hover`, `--own-link`)과 `tr.own`·`tr.broken` 색 규칙을 index · group · statusbar 에서 지웠다(`own`·`broken` 클래스는 표식으로만 남는다). 붉은 글자(`--bad`: 끊긴 선행 글자, P0 테두리, 그래프의 끊긴 간선)와 상태 표시줄 항목의 붉은 "오너가 할 일 있음" 상태는 행 배경이 아니라서 그대로다.
- **행 높이 하나(40px)**: 넓은 화면의 모든 표 데이터 행이 40px 이다. hallmark 간격 단위 `--s2`(8px)의 5배이고, 셀은 `height: 40px` + 위아래 `--s1`(4px) 안쪽 여백, 줄 높이 20px. 진행 중 표의 묶음 머리 줄과 하위 항목 줄, 보류, group 의 표도 같은 값이다. 버튼은 높이 32px → 28px, 모서리 `--r3` → `--r2` 로 줄여 행 안에 들어간다(행 쪽을 키우지 않았다). 넘치는 글이 있는 칸만 그 행을 키운다(group 의 릴리스 묶음 "머지" 행처럼 한 칸에 줄이 둘인 곳).
- **360px 카드 리듬**: 한 절의 카드는 같은 안쪽 여백(`--s2` · `--s1`)과 줄 높이(제목 20px, 값 16px)를 쓴다. 버튼 카드의 버튼은 32px 로 유지한다(좁은 화면은 손가락으로 누르므로. hallmark 에 터치 목표 크기 규칙은 없어서 44px 로 올리지는 않았다). 줄 수는 내용이 정한다: 값이 길면 값 줄이 둘이 되는 카드가 있다.
- **group 넓은 화면 배치**: 열 비율 **1fr : 1fr**(간격 `--s6` 32px). 왼쪽은 그래프와 그 바로 아래 간선 종류 범례, 오른쪽은 크리티컬 패스 · 스택 PR 체인 · 릴리스 묶음 · 끊긴 선행. 두 열은 같은 위쪽 선에서 시작하고 왼쪽이 높이를 정한다. 오른쪽은 그 높이 안에서 스크롤한다(`contain: size`, 보이는 스크롤바, 아래쪽 흐림, 표 제목은 위에 붙는다). 이전은 그래프 400px 열에 표 다섯이 있어 그래프 아래가 600px 비었다. 범례의 열 너비는 56 · 112px 이고 한 줄에 들어간다. 360px 은 열이 하나이고 순서는 그래프, 범례, 표 넷이며 안쪽 스크롤은 없다. 이전 화면은 `shots/before/` 에 있다.

## 글자 대비 (WCAG, 본문 AA 4.5 이상)

행 배경이 보통 배경(`--paper`, 행 hover 는 `--paper-2`, 묶음 머리 줄과 그 hover 는 `--paper-2` · `--paper-3`)이 되어 붉은 행 위에서 잰 이전 표를 내렸다. 독립 검수가 OKLCH 를 sRGB 로 바꿔 계산한 값이다.

| 글자 | 라이트 paper | paper-2 | paper-3 | 다크 paper | paper-2 | paper-3 |
|---|---|---|---|---|---|---|
| ink | 17.02 | 15.87 | 14.86 | 16.04 | 14.86 | 13.42 |
| ink-2 | 8.48 | 7.90 | 7.40 | 10.24 | 9.49 | 8.57 |
| muted (id, —, 라벨) | 5.76 | 5.37 | 5.03 | 6.90 | 6.39 | 5.77 |
| 링크 accent | 5.37 | 5.01 | 4.69 | 7.13 | 6.61 | 5.97 |
| 붉은 글자 bad | 6.33 | 5.90 | 5.52 | 7.19 | 6.66 | 6.01 |

모든 조합이 4.5 를 넘고 가장 낮은 값은 라이트 paper-3 위 accent 링크 4.69 다. 이전 hover 에서 4.5 에 못 미치던 accent 링크(4.36)가 사라져 링크색 교체(`--own-link`)는 필요 없다.

## 상태 표시줄 색

붉은 바탕 `--bad` 위 글자 `--paper`. 라이트 `oklch(50% 0.18 27)` 위 `oklch(98.6% 0.004 255)`, 다크 `oklch(72% 0.16 25)` 위 `oklch(17% 0.008 255)`. 대비는 라이트 6.33, 다크 7.19. 붉지 않은 상태의 글자(ink 대 paper-3)는 라이트 14.86, 다크 13.42.

## 스크린샷

`shots/` 에 index · group · statusbar × 360px · 넓은 화면(1280px) × 라이트 · 다크. 360px 은 2배 해상도. iframe 안에서 실제 360px 뷰포트로 찍었다. `group-wide-light-right-scrolled.png` 는 오른쪽 열을 끝까지 스크롤한 모습이다. `shots/before/` 는 group 넓은 화면의 이전 모습(라이트 · 다크)이다.
